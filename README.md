# 💳 Bank Management System v1

A modular Java-based banking backend system built to simulate real-world core banking operations. This project includes account creation, transaction handling, and basic auditing capabilities — developed to demonstrate backend engineering skills, object-oriented design, and state management.

---

## 📌 Overview

This project simulates core features of a traditional banking system, handling accounts, authentication, fund transfers, and transaction logging. Designed as an educational prototype, it emphasizes clean design, input validation, and backend architecture.

---

## ⚙️ Features

- 🔐 **User Authentication**  
- 🏦 **Account Creation and Management**  
- 💸 **Balance Inquiry and Fund Transfers**  
- 📊 **Transaction Logging**  
- 🔄 **Command-line driven interface**

---

## 🧱 Tech Stack

| Component    | Technology                     |
|--------------|-------------------------------|
| Language     | Java (OOP, file I/O, exception handling) |
| Data Storage | Local file system (text-based simulation) |
| Build Tool   | javac / Java CLI               |
| Runtime      | Java 8 or higher               |
